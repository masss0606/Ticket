# 奥冠体育游泳馆抢票助手

## 首次准备

使用 Windows 和电脑微信。首次安装依赖，在项目目录打开 PowerShell 执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

首次抓取 Token 还需运行 `.\.venv\Scripts\mitmdump.exe`，将本机生成的 `%USERPROFILE%\.mitmproxy\mitmproxy-ca-cert.cer` 导入当前用户的“受信任的根证书颁发机构”，然后按 `Ctrl+C` 退出。已经能正常刷新 Token 的电脑可跳过。

## 使用步骤

1. **打开并登录电脑微信**，手动打开一次“奥冠体育”小程序，完成登录并进入预约页面。
2. 返回微信 **“发现 → 小程序”**，确认“奥冠体育”出现在首页可见的 **“最近使用”或“我的常用”** 中。
3. 双击 **`抢票助手.bat`** 启动助手。
4. 点击 **“刷新 Token”**，等待成功；再点击 **“检测 Token”**，确认显示“有效”。可用 **“测试查询”** 立即发送只读请求，检查接口响应，不会下单。
5. 设置 **“开抢时间”**：留空为下一个北京时间 **00:00**；也可填写 `14:30` 或 `14:30:15`，已过的时刻会顺延到明天。
6. 建议至少提前 **40 分钟**点击 **“开始抢票”**，核对日志里的日期和目标时间，保持助手运行。
7. 开抢后到小程序核对订单。需要中止时点击 **“停止”**，已创建的订单不会撤销。

**“开始抢票”会真实下单，并默认自动确认明确为零元的订单；收费订单需自行处理。**

## 自动刷新时间

- **开抢前 33 分钟**启动首轮刷新，要求在**前 30 分钟**完成刷新和联网校验。
- **开抢前 13 分钟**开始复检准备，必要时补刷；**前 10 分钟**实际发请求确认 Token 有效。
- 最后 10 分钟约每分钟检查一次；失效自动补刷，刷新或校验失败会停止抢票。

晚启动会提示并立即补做准备，剩余时间不足时会取消任务。等待期间保持电脑唤醒、桌面解锁、微信窗口可见；自动刷新时暂时不要操作鼠标或切换微信页面。
